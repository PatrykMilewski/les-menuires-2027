# Les Menuires 2027

Publiczny plan wyjazdu: Gdańsk → Warszawa → Lyon → Les Menuires.

Wszystkie ceny na osobę. Dane i ograniczenia weryfikacji opisane przy każdej pozycji. Cenniki nie stanowią potwierdzenia dostępności. Główny termin 16–23 stycznia 2027; porównanie 23–30 stycznia.

TypeScript strict + Vite + Leaflet. `npm ci`, `npm run build` (z kontrolą typów), `npm run dev`.

GitHub Pages publikuje katalog `dist` po zmianach na `main`. Mapa panoramiczna dostarczona przez użytkownika; nakładka wskazuje orientacyjny obszar proponowanego noclegu, a nie dokładne położenie na mapie geograficznej.

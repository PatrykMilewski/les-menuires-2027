# Les Menuires 2027

Publiczny plan wyjazdu: Gdańsk → Warszawa → Lyon → Les Menuires.

Wszystkie ceny na osobę. Dane i ograniczenia weryfikacji opisane przy każdej pozycji. Cenniki nie stanowią potwierdzenia dostępności. Porównanie obejmuje 23–30 stycznia, 6–13 i 20–27 lutego oraz 6–13 marca 2027.

Loty zaktualizowane 01.11.2026 według odczytów Wizz przekazanych przez użytkownika: 1108 / 877 / 431 / 902 zł na osobę w obie strony. Nie dodajemy opłaty serwisowej eSky do ceny bezpośredniej Wizz. Bagaż pozostaje szacunkiem z września. Nie potwierdzono koszyka przewoźnika, warunków taryfy ani liczby miejsc w danej cenie. Noclegi sprawdzone 01.11.2026 osobno dla 2, 4, 5 i 6 dorosłych: 128 wariantów pierwotnych obiektów oraz 16 wariantów zamienników. Pozostałe 48 kombinacji zamienników pozostaje bez wyceny. Pelvoux/Jettay są zajęte i nie dostarczają kwot do budżetów. Kalkulator używa aktualnych wycen jednego lokalu na 7 nocy, z wyborem najtańszej sprawdzonej dostępnej oferty po zmianie daty lub liczby osób; można wybrać ręcznie inną dostępną ofertę. Odczyty Booking pochodzą z sesji z programem Genius i mogą zależeć od uprawnień. Szczegóły, opłaty, anulowanie i źródła: `public/noclegi-2026-11-01.md` oraz `.json`.

TypeScript strict + Vite + Leaflet. `npm ci`, `npm run build` (z kontrolą typów), `npm run dev`.

GitHub Pages publikuje katalog `dist` po zmianach na `main`. Mapa panoramiczna dostarczona przez użytkownika; nakładka wskazuje orientacyjny obszar proponowanego noclegu, a nie dokładne położenie na mapie geograficznej.
